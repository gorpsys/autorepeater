# CHANGELOG

Значимые изменения по версиям. Правила выпуска — в
[техническом README](scripts/README.md#версии-и-выпуск).
Исторические версии назначены ретроспективно; подробная история коммитов
и обоснования тегов — в [истории версий](docs/history/versioning.md).

## Не выпущено

## [5.3.0](https://github.com/gorpsys/autorepeater/compare/v5.2.1...v5.3.0) - 2026-10-16

- Добавлен RUB/CNY sandbox-набор штатного приложения; INDEX распознаёт облигации.
- INDEX выбирает валюту инструмента по `preferred_currency` (default RUB);
  валютные E2E явно задают CNY. Несколько оставшихся кандидатов дают ошибку.
- Убрано повторное удержание `cash_floor` из доступных денег и собственных
  денежных лимитов; комиссии могут расходовать уже предусмотренный резерв.
- Добавлен чистый план валютного финансирования с отдельными денежными
  пулами владельцев и подключён SDK runtime RUB-оценки и исполнения FX.
- Прямые BESTPRICE-обмены подтверждаются перед зависимыми покупками;
  валюты всего плана проверяются до первой заявки, остатки и собственные
  лимиты перечитываются без повторного удержания резерва. Неполные денежные
  факты не разрешают чужую выручку или повторную отправку.
- Отчёт разделяет native/RUB-оценки, FX-курсы с временем, валютные потребности
  и остатки, подтверждённые комиссии и денежные границы; объясняет отсрочки.
- Исправлены последовательные обратные FX, выбор достаточного источника
  по исполнимым лотам и потеря обеспеченного лота при округлении долей владельцев.
- Безопасные логи поясняют выбор инструмента в E2E и отдельно показывают
  несовпадение UID, время и возраст отклонённого стакана.

## [5.2.1](https://github.com/gorpsys/autorepeater/compare/v5.2.0...v5.2.1) - 2026-10-16

- Sandbox E2E проверяет полный набор сценариев из независимой коллекции
  точного SHA, включая исходные попытки, допустимые повторы и очистку.
- Новый workflow явно выбирает протокол `retry-v2`; прежний workflow
  получает совместимый `retry-v1` без изменения формата отчётов.
- Основной и резервный деплой выбирают функцию по неизменному ID и проверяют
  его до загрузки пакета, в ответе создания версии и при чтении результата.

## [5.2.0](https://github.com/gorpsys/autorepeater/compare/v5.1.2...v5.2.0) - 2026-10-14

- CLI выводит версию по `--version` или `-v` без запуска стратегии и чтения токена.
- Обязательный `Offline checks` проверяет версию PR по CHANGELOG и CLI:
  номер должен быть больше опубликованных тегов и версии базовой ветки.
- После мержа в master автоматически создаётся аннотированный тег выпуска.
- Разделены документация приложения и технических скриптов; добавлены
  CHANGELOG и ретроспективные теги версий.
- AGENTS.md сокращён до основных правил; подробные контракты и история
  находок вынесены в тематический справочник с индексом.
- README изложен проще, с объяснениями терминов и пошаговыми расчётами;
  сохранность фактов проверена сравнением и холодным чтением.
- Добавлены инструкции локальной установки, токенов, собственных конфигов,
  чтения debug-отчёта и ручной песочницы; пояснены риски, расписание и логи.
- Уточнены настройки одной бумаги, смысл допуска округления, действия после
  неподтверждённой заявки и перенос личного конфига в облако через свой форк.

## [5.1.2](https://github.com/gorpsys/autorepeater/compare/v5.1.1...v5.1.2) - 2026-10-13

- Добавлен production-деплой через GitHub OIDC и Object Storage; исправлены
  обмен токенов, настройка yc и проверки версии функции.
  Связанный блок PR #29–#33 и #35 проверен автономным деплоем из `master`
  через GitHub Actions.
- Добавлен прогресс live E2E.
- Проверенная установка SDK 1.51.0 с резервным wheel, полным runtime lock
  и receipt окружения Make; строгая проверка hashes и одобрений расхождений.
- Vendored и offline режимы облачного архива, отдельный ручной резервный
  деплой с действующими production gates.
- Обязательный сетевой package smoke после offline coverage и отдельный
  ручной запуск той же проверки; лицензии и notices runtime payload.
