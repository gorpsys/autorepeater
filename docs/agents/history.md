# История находок для агентов

Индекс граблей и обоснований, выделенных из инструкций проекта.
Записи H01–H30 основаны на [снимке от 2026-10-10](history/2026-10-10-guidance.md).
Новые находки имеют отдельные ссылки на проверенные источники.
Действующие способы работы описаны в тематических документах [индекса](README.md).
Историческое объяснение само по себе не меняет текущий контракт.

## Пополнение истории

Новая запись получает следующий ID, краткий контрпример, причину,
ссылку на действующий способ и источник свидетельства (PR, коммит, лог
или отчёт без секретов). Для нового инцидента указываются его дата и проверенный
источник. Одна находка — одна запись; отменённое решение помечается историческим.
Снимки прошлых инструкций читаются только для выяснения конкретного обоснования.
