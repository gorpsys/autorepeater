## Статус документов

Тематические инструкции действующие; их перенос из AGENTS.md сохраняет
контракт. README описывает актуальное приложение, scripts/README.md —
технические команды и workflow. Исторические таблицы и снимки объясняют
прежние решения и не являются самостоятельной спецификацией runtime.

[История находок](history.md) содержит индекс H01–H40 и порядок добавления записей.
[Снимок инструкций от 2026-10-10](history/2026-10-10-guidance.md) сохраняет
исходный текст для проверки переноса; он не загружается как AGENTS.md.

При изменении контракта обновляются соответствующий тематический документ,
тесты и краткая запись CHANGELOG. Обоснование или новая находка добавляются
в историю со ссылкой на источник.
