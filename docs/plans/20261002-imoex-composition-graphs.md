## Что означает разбиение

При независимых случайных изменениях цен нет единого бюджета появления хвоста:
границы различаются по сценариям. Поэтому выполнена условная группировка:
на панели N показан максимум ошибки при данном бюджете только среди сценариев,
где основная цель содержит ровно N инструментов. При смене количества бумаг
случай относится к другой панели. Это не непересекающаяся разбивка общей
оси бюджета и не утверждение, что все сценарии одной панели содержат одинаковые
тикеры. При одинаковом N состав конкретных тикеров может различаться.

Области бюджета на разных панелях перекрываются. Там, где для N нет наблюдений,
линия прерывается. Возвращение размера N после временного изменения размера
не скрывается. Шкала Y собственная для каждой панели, единицы — проценты.
Результаты не сглажены. Максимумы на разных бюджетах могут относиться к разным
ценовым сценариям: график не является траекторией одного портфеля.

## Данные и проверка

Использованы те же 1000 случайных сценариев плюс исходные цены, seed 20261002,
независимые равномерные сдвиги каждой цены от -10% до +10% с шагом 1%.
Бюджет от 50000 до 1000000 рублей включительно, шаг 1000.
Метрика прежняя: точно достигнутая основная цель против контрольной цели,
построенной от стоимости вложенных бумаг. Никаких API-запросов и сделок.

Проверено 951951 случаев, пустых целей нет. Получены 4984 условные точки
(N, бюджет), принадлежащие 37 размерам цели. N=28 в выборке не встретился.
После объединения условных групп повторно получены все 95 максимумов
[предыдущей таблицы](20261002-imoex-random-drift-calibration.csv), с допуском
1e-24 для незначимого последнего разряда Decimal. Исходные файлы проверены
по SHA-256 предыдущего прогона.

## Воспроизведение

Временные скрипты:

- `/tmp/autorepeater-calibrate-composition-curves.py` — расчёт через текущие
  чистые функции стратегий, независимые сценарии вычисляются в шести процессах.
- `/tmp/plot-imoex-composition-curves.py` — построение графиков.
- `/tmp/autorepeater-composition-drift-curves.json` — все условные точки,
  число поддерживающих сценариев и номер сценария максимума.

Это эмпирические максимумы, не гарантированные пределы. Рабочий код,
конфиги, исходный план и параметры торговли не менялись. Новые зависимости
проекта не добавлялись; библиотеки построения графиков находятся в /tmp.
