# Случайная калибровка ложного отклонения IMOEX

## Методика

- Текущий встроенный конфиг IMOEX и реальные цены сохранённого снимка
  `test/data/imoex_snapshot.json`; никаких API-запросов и заявок.
- Бюджеты от 50000 до 1000000 рублей включительно, шаг 1000.
- 1000 случайных ценовых сценариев плюс один исходный без изменения цен.
- Каждая цена независимо умножается на `1 + change / 100`, где change —
  случайное целое от -10 до 10 включительно: шаг изменения цены 1%.
- Равномерное дискретное распределение; seed `20261002`; тикеры перебираются
  по алфавиту. Один набор сценариев используется для всех бюджетов.
- В каждом случае фактический портфель равен основной цели для этого бюджета
  и этих цен. Контроль строится от стоимости купленных бумаг, как в плане.
  Вычисляется половина суммы модулей разниц нормированных весов без денег.
  Это ложное отклонение контрольной схемы, а не отклонение индекса в реальности
  и не поведение портфеля, удержанного при изменении рыночных цен.
- Денежная арифметика Decimal, точность 28; версия Python 3.12.
- Для каждого диапазона 10000 рублей берётся максимум по всем входящим
  шагам бюджета и всем 1001 сценарию. Интервалы `[from, to)`; последний
  `[990000, 1000000]` включает конечную точку.

Проверено 951951 случаев; пустых основных или контрольных целей нет.
Для всех 95 максимумов повторно проверены seed/ценовые изменения, целевые
количества, границы и рассчитанное отклонение. Незначимая разница последнего
разряда Decimal при порядке суммирования ограничена допуском `1e-24`.

## Ограничения

Это эмпирический максимум по заданной выборке одной базы цен, не гарантированная
верхняя граница и не готовые торговые лимиты. При расширении с 500 до 1000
случайных сценариев максимумы выросли в 50 из 95 диапазонов; самый большой
дополнительный рост составил 3.565620687254252579437364940 процентного пункта.
Считать статистическую сходимость достигнутой нельзя.

Независимые равномерные сдвиги — синтетический стресс, не модель вероятностей
реального рынка. Изменения лотности, состава конфига и цен за пределами ±10%
не проверены. В таблице бюджет выделен самому IMOEX, а не всему BALANCED.
Порог политики и конфиги стратегий по результатам прогона не изменены.
